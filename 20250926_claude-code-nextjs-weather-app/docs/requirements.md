# 天気予報アプリ 要件定義書

## 概要
OpenWeatherMap APIを使用したシンプルな天気予報Webアプリケーション。現在の天気と5日間の予報を日本語で表示する。

## 技術スタック
- **フレームワーク**: Next.js 15.5.0 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS v4
- **API**: OpenWeatherMap API (無料プラン)

## 機能要件

### 1. 都市検索機能
- テキスト入力による都市名検索
- デフォルト都市: 東京
- 検索ボタンまたはEnterキーで検索実行

### 2. 現在の天気表示
表示項目：
- 都市名
- 現在の気温（摂氏）
- 天気の説明（晴れ、曇り、雨など）
- 天気アイコン
- 最高気温/最低気温

### 3. 5日間天気予報
表示項目（1日ごと）：
- 日付
- 天気アイコン
- 最高気温/最低気温

## 非機能要件

### UI/UX設計
- **デザイン方針**: クリーンでミニマルなデザイン
- **カラースキーム**: ライトモードのみ
- **レイアウト**: カード型コンポーネント
- **レスポンシブ**: モバイル・デスクトップ対応
- **言語**: 日本語表示

### API設定
- **エンドポイント**: 
  - 現在の天気: `/weather`
  - 5日間予報: `/forecast`
- **パラメータ**:
  - 言語: `lang=ja`
  - 単位: `units=metric`
- **レート制限**: 無料プラン（60 calls/minute）

### エラーハンドリング
- 都市が見つからない場合のエラーメッセージ
- API接続エラーの処理
- ローディング状態の表示

## 環境変数

**設定済み**: `.env.local`ファイルに以下の環境変数が設定されています。

```env
OPEN_WEATHER_API_KEY=（設定済み）
```

**注意事項**:
- 環境変数名は `OPEN_WEATHER_API_KEY` を使用
- クライアントサイドでAPIキーを使用する場合は、Next.jsのAPI Routesを経由することを推奨（セキュリティのため）
- 直接ブラウザに露出させる場合は `NEXT_PUBLIC_` プレフィックスが必要ですが、セキュリティ上API Routesの使用を推奨
