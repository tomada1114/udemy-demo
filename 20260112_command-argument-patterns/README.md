# カスタムコマンドの引数パターン デモ環境

## 概要

このデモでは、カスタムコマンドで引数を受け取る2つの方法を学びます。

- `$ARGUMENTS`: すべての引数を1つの文字列として取得
- `$0, $1, $2...`: 位置指定で個別に取得（ゼロ始まり）

## ファイル構成

```
.
├── .claude/
│   └── commands/
│       ├── fix-issue.md      # $ARGUMENTS を使った例
│       ├── search-error.md   # 可変長の引数を受け取る例
│       └── compare.md        # $1, $2 を使った比較例
├── src/
│   ├── old.js                # 比較用サンプル（古いバージョン）
│   └── new.js                # 比較用サンプル（新しいバージョン）
├── CLAUDE.md
└── README.md
```

## 動作確認

### 1. $ARGUMENTS の確認

```bash
# Issue番号を渡す
/fix-issue 123

# エラーメッセージを渡す（スペースを含む長い文字列）
/search-error TypeError: Cannot read property 'map' of undefined
```

### 2. 位置引数 $0, $1 の確認

```bash
# 2つのファイルを比較
/compare src/old.js src/new.js
```

## 引数入力のコツ

1. `/fix-issue` とタイプ
2. **Tab キーでコマンドを選択**
3. スペースを入力
4. 引数を入力
5. Enter で実行

**注意**: すぐに Enter を押すと引数なしで実行されてしまいます。

## 学習ポイント

| 変数 | 説明 | 用途 |
|------|------|------|
| `$ARGUMENTS` | すべての引数を1つの文字列で取得 | 可変長の入力、エラーメッセージ |
| `$0, $1, $2...` | 位置指定で個別に取得（ゼロ始まり） | 複数の明確な引数、ファイル比較 |
