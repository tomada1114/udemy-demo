# サンプルドキュメント

## 概要

これはJavaScriptとTypeScriptを使ったWebアプリケーションです。
ソースコードはGitHubで管理しています。

フロントエンドはReactで構築し、バックエンドはNode.jsで動作します。
開発環境はVS Codeを推奨しています。

## 使い方

### インストール

```bash
npm install
```

### 開発サーバー起動

```bash
npm run dev
```

### ビルド

```bash
npm run build
```

## 注意事項

- Node.js v18以上が必要です
- 環境変数の設定は`.env.example`を参考にしてください
