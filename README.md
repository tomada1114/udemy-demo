## 使い方

1. 講座内のリンクから該当ディレクトリにアクセス
2. 各ディレクトリ内のREADME.mdで詳細な手順を確認
3. ローカルにクローンして動作確認

```bash
git clone https://github.com/tomada1114/udemy-demo.git
cd udemy-demo/ディレクトリ名
claude  # Claude Codeを起動
```

## 前提条件

- Claude Code がインストールされていること
- Claude サブスクリプション（Pro または Max）
