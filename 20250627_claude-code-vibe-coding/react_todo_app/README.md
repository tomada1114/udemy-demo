# React Todo App

モダンでスタイリッシュなTodoアプリケーション。React + TypeScriptで実装されており、美しいグラスモーフィズムデザインとスムーズなアニメーションが特徴です。

## 機能

### 基本機能
- ✅ **タスクの作成**: 新しいタスクを簡単に追加
- ✏️ **タスクの編集**: クリックして即座に編集可能
- 🗑️ **タスクの削除**: 不要なタスクをワンクリックで削除
- ✔️ **完了状態の管理**: チェックボックスで完了/未完了を切り替え
- 🔄 **ドラッグ&ドロップ**: タスクを直感的に並び替え
- 💾 **自動保存**: LocalStorageによるデータの永続化

### UI/UX機能
- 📱 **レスポンシブデザイン**: モバイル・タブレット・デスクトップに対応
- ✨ **スムーズなアニメーション**: 全ての操作に心地よいトランジション
- 🎨 **グラスモーフィズムデザイン**: 半透明の美しいモダンUI
- 📊 **リアルタイム統計**: アクティブ・完了・合計タスク数を表示
- 🕐 **相対時間表示**: 「5分前」「昨日」などわかりやすい時間表示

## 技術仕様

### 使用技術
- **React** 18.3.1
- **TypeScript** 4.9.5
- **React DOM** 18.3.1
- **CSS3** (CSS Variables, Flexbox, Grid)

### アーキテクチャ
```
src/
├── components/
│   ├── TodoForm.tsx    # タスク入力フォーム
│   ├── TodoList.tsx    # タスク一覧表示・並び替え
│   └── TodoItem.tsx    # 個別タスク表示・編集
├── types/
│   └── todo.ts         # TypeScript型定義
├── App.tsx            # メインコンポーネント・状態管理
├── App.css            # アプリケーション全体のスタイル
└── index.css          # グローバルスタイル・CSS変数
```

### データ構造
```typescript
interface Todo {
  id: string;          // ユニークID
  text: string;        // タスクの内容
  completed: boolean;  // 完了状態
  createdAt: Date;     // 作成日時
  updatedAt: Date;     // 更新日時
}
```

## 使い方

1. **タスクの追加**: 上部の入力フィールドにタスクを入力して「追加」ボタンをクリック
2. **タスクの編集**: タスクのテキストをクリックして編集モードに入る
3. **完了状態の切り替え**: 左側のチェックボックスをクリック
4. **タスクの削除**: ホバー時に表示される削除ボタンをクリック
5. **並び替え**: タスクをドラッグして好きな位置にドロップ
6. **完了タスクの一括削除**: 下部の「完了したタスクをクリア」ボタンをクリック

- Secondary: #ec4899 (ピンク)
- Background: #0a0a0a (ディープブラック)
- Surface: rgba(255, 255, 255, 0.05)
- Success: #10b981 (エメラルド)
- Danger: #ef4444 (レッド)

### アニメーション
- fadeInUp: 要素の表示時
- pulse: ドラッグ位置のインジケーター
- トランジション: 0.3秒の滑らかな変化
