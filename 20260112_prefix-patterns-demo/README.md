# @ と ! プレフィックス デモ環境

カスタムコマンドで使える2種類のプレフィックスを学ぶデモ環境です。

## 学ぶこと

1. **@プレフィックス** - ファイルの内容を読み込む
2. **!プレフィックス** - Bashコマンドを実行する
3. **ディレクトリ整理** - `:` 区切りでコマンドをグループ化

## セットアップ

```bash
# このフォルダに移動
cd ~/Desktop/udemy-demo/20260112_prefix-patterns-demo

# Gitリポジトリを初期化（!プレフィックスのデモ用）
git init
git add .
git commit -m "初回コミット"
```

## デモ手順

### 1. @プレフィックス: ファイル比較

```bash
# 2つのファイルを比較
/compare src/old.js src/new.js
```

`@$1` と `@$2` でファイル内容を読み込んで比較します。

### 2. @プレフィックス: コードレビュー

```bash
# ファイルをレビュー（読み取り専用）
/review src/new.js
```

`allowed-tools: Read, Glob, Grep` で読み取り専用に制限。

### 3. !プレフィックス: 現在地確認（シンプル例）

```bash
# 今どこで作業しているか確認
/where
```

`!pwd` で現在のディレクトリを取得。準備不要でシンプル。

### 4. !プレフィックス: コミットメッセージ作成

```bash
# 何か変更を加える
echo "// 追加コメント" >> src/new.js

# ステージングしてコミットメッセージを生成
git add src/new.js
/commit-msg
```

`!git diff --staged` でステージング済みの変更を自動取得。

### 5. ディレクトリ整理: サブディレクトリコマンド

```bash
# git/ サブディレクトリのコマンド
/git:status

# test/ サブディレクトリのコマンド
/test:check
```

## ファイル構成

```
.claude/commands/
├── compare.md        @プレフィックス: ファイル比較
├── review.md         @プレフィックス: コードレビュー（読み取り専用）
├── where.md          !プレフィックス: 現在地確認（シンプル例）
├── commit-msg.md     !プレフィックス: コミットメッセージ作成
├── git/
│   └── status.md     サブディレクトリ例: /git:status
└── test/
    └── check.md      サブディレクトリ例: /test:check
src/
├── old.js            比較元ファイル
└── new.js            比較先ファイル（リファクタリング後）
```

## ポイント

| プレフィックス | 用途 | 注意点 |
|--------------|------|--------|
| `@` | ファイル参照 | `@$1`, `@$ARGUMENTS` で引数と組み合わせ可 |
| `!` | Bash実行 | `allowed-tools: Bash(...)` が必須 |

## 注意事項

- `!プレフィックス` を使うには `allowed-tools` で Bash を許可する必要があります
- セキュリティのため `Bash(git:*)` のようにパターンで制限しましょう
