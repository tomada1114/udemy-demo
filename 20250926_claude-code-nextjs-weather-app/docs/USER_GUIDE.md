# 天気予報アプリ ユーザーガイド

## 🌤️ はじめに

このアプリは、世界中の都市の天気情報を簡単に確認できるWebアプリケーションです。現在の天気と5日間の天気予報を、見やすい絵文字とともに表示します。

## 📱 主な機能

### 現在の天気表示
- 🌡️ リアルタイムの気温
- 🌤️ 天気の状態（絵文字で表示）
- 📊 最高・最低気温
- 💧 湿度
- 💨 風速

### 5日間天気予報
- 📅 日付と曜日
- 🌡️ 各日の最高・最低気温
- 🌤️ 天気予報（絵文字で表示）

## 🚀 使い方

### 1. アプリケーションへのアクセス

ブラウザで以下のURLにアクセスしてください：
```
http://localhost:3000
```

### 2. 初期表示

アプリを開くと、自動的に**東京**の天気が表示されます。

![初期画面イメージ]
- 画面上部：都市検索バー
- 中央：現在の天気情報カード
- 下部：5日間の天気予報カード

### 3. 都市の検索

#### 検索方法

1. **検索バーに都市名を入力**
   - 日本語または英語で入力可能
   - 例：「大阪」「Osaka」「ニューヨーク」「New York」

2. **検索を実行**
   - 「検索」ボタンをクリック
   - または、Enterキーを押す

3. **結果の表示**
   - 天気情報が自動的に更新されます

### 4. 天気情報の見方

#### 現在の天気カード

```

          晴れ

最高: 28°C    最低: 22°C
湿度: 65%     風速: 3.5 m/s
```

#### 予報カード（5日分）

```

[曜日]
 ⛅

```

### 5. 絵文字の意味

| 絵文字 | 天気 | 説明 |
|--------|------|------|
| ☀️ | 晴れ（昼） | 快晴 |
| 🌙 | 晴れ（夜） | 夜の快晴 |
| ⛅ | 薄曇り（昼） | 晴れ時々曇り |
| ☁️ | 曇り | 曇り空 |
| 🌧️ | 雨 | 降雨 |
| 🌦️ | にわか雨（昼） | 時々雨 |
| ⛈️ | 雷雨 | 雷を伴う雨 |
| ❄️ | 雪 | 降雪 |
| 🌫️ | 霧 | 霧・もや |

## ⚠️ エラーメッセージと対処法

### 「都市が見つかりませんでした」

**原因**：入力した都市名が認識されない

**対処法**：
- スペルを確認する
- 英語名で再度試す
- 大都市名で検索する

### 「天気情報の取得に失敗しました」

**原因**：ネットワークエラーまたはAPIの問題

**対処法**：
- インターネット接続を確認
- しばらく待ってから再度試す
- ページを更新する（F5キー）

## 💡 便利な使い方

### よく見る都市を素早く検索

1. **ブックマーク機能の活用**
   - よく検索する都市を検索した状態でブックマーク
   - 次回からワンクリックでアクセス

2. **検索履歴の利用**
   - ブラウザの検索履歴から選択
   - 入力の手間を省略

### 旅行計画での活用

1. **複数都市の天気確認**
   - 旅行先の都市を順番に検索
   - 5日間の予報で旅行期間の天気を確認

2. **服装の準備**
   - 最高・最低気温を確認
   - 天気に応じた服装を準備

## 🔄 データの更新について

- **自動更新**：ページを更新するたびに最新データを取得
- **キャッシュ**：同じ都市は5分間キャッシュされます
- **最新情報**：より新しい情報が必要な場合は、5分後に再検索

## ❓ よくある質問

### Q: 天気情報はどのくらい正確ですか？

A: OpenWeatherMap APIの公式データを使用しており、世界中の気象観測所からの情報を基にしています。

### Q: なぜ5日間しか予報が見られないのですか？

A: 無料版のAPIの制限により、5日間の予報となっています。

### Q: 現在地の天気を自動で表示できますか？

A: 現在のバージョンでは手動で都市名を入力する必要があります。

### Q: オフラインで使用できますか？

A: いいえ、天気データの取得にはインターネット接続が必要です。
