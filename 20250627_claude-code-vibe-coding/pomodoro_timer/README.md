# ポモドーロタイマー

React + TypeScript + Vite + Tailwind CSS + shadcn で構築されたモダンなポモドーロタイマーアプリケーション。

## 🍅 概要

ポモドーロテクニックを実践するための一画面完結型タイマーアプリです。集中力を高めて生産性を向上させることができます。

## ✨ 機能

### 📋 基本機能
- ✅ 作業時間と休憩時間を分と秒で自由に設定可能
- ✅ タイマーの開始・停止・リセット機能
- ✅ セッション切り替え（作業 ⇄ 休憩）
- ✅ 作業・休憩終了時の音声通知
- ✅ 円形プログレスバーによる視覚的な進捗表示
- ✅ リアルタイムでの進捗率表示

### 🎨 UI/UX
- ✅ レスポンシブデザイン（モバイル・タブレット・デスクトップ対応）
- ✅ スムーズなアニメーション効果
- ✅ モダンでスタイリッシュなデザイン
- ✅ ダークモード対応
- ✅ 視覚的にわかりやすいセッション表示（🍅作業 / ☕休憩）

### ⚙️ 設定機能
- ✅ プリセット時間設定（25分/5分、45分/15分、50分/10分、90分/20分）
- ✅ カスタム時間設定（0-99分、0-59秒）
- ✅ 設定パネルの開閉機能

### 📊 統計情報
- ✅ 現在のセッション種別表示
- ✅ リアルタイム進捗率表示
- ✅ タイマー状態表示（実行中/停止中）

## 🚀 技術スタック

- **フロントエンド**: React 19.1.0
- **言語**: TypeScript 5.8.3
- **ビルドツール**: Vite 7.0.0
- **スタイリング**: Tailwind CSS 4.1.11

## 🎯 使用方法

### 基本的な使い方
1. **設定**: 「タイマー設定」ボタンをクリックして作業時間と休憩時間を設定
2. **開始**: 「開始」ボタンをクリックしてタイマーを開始
3. **進行**: 円形プログレスバーで進捗を確認
4. **通知**: セッション終了時に音声通知が再生
5. **切り替え**: 自動的に作業 ⇄ 休憩セッションが切り替わり

### 操作ボタン
- **開始/停止**: タイマーの開始と一時停止
- **リセット**: タイマーを初期状態に戻す
- **スキップ**: 現在のセッションを終了して次のセッションに切り替え

### プリセット設定
- **25分/5分**: 標準的なポモドーロテクニック
- **45分/15分**: 長時間集中作業向け
- **50分/10分**: 大学の講義時間向け
- **90分/20分**: 深い集中作業向け
